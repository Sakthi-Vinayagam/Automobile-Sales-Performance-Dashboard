# 🚗 Automobile Sales & Performance Analytics Dashboard

An interactive **Automobile Sales & Performance Analytics Dashboard** developed using **Microsoft Power BI** to analyze sales performance, dealer achievement, customer behavior, vehicle models, and regional sales performance.


## 📊 Dashboard Preview

[📄 View Automobile Sales & Performance Dashboard](Automobile%20Sales%20%26%20Performance%20Dashboard.pdf)

## 🎯 Project Objective

The objective of this project is to transform automobile sales data into an interactive business intelligence dashboard that helps analyze:

- Overall sales performance
- Sales target vs actual performance
- Dealer performance and achievement
- Vehicle model performance
- State-wise sales
- Customer type analysis
- Sales channel performance
- Transmission-wise sales
- Quarterly sales trends

## 🛠️ Tools & Technologies

- **Microsoft Power BI**
- **Power Query**
- **DAX**
- **Microsoft Excel**

## 📌 Key Performance Indicators

| KPI | Description |
|---|---|
| 💰 Total Sales | Overall automobile sales generated |
| 🚘 Units Sold | Total number of vehicles sold |
| 💵 Average Selling Price | Average selling price of vehicles |
| 📈 Sales Growth | Growth in sales performance |
| 🎯 Dealer Sales Achievement | Actual sales compared with annual target |
| 🎯 Dealer Unit Achievement | Actual units sold compared with annual target |

## 📈 Dashboard Analysis

### 1. Sales Performance
Analyzes overall sales performance and compares actual sales against annual sales targets.

### 2. Dealer Performance
Identifies top-performing dealers and evaluates dealer sales and unit achievement against their annual targets.

### 3. Vehicle Analysis
Provides insights into sales performance across different car models, brands, fuel types, and transmission types.

### 4. Regional Analysis
Analyzes state-wise automobile sales to identify regions with higher sales contribution.

### 5. Customer & Channel Analysis
Examines sales based on customer type and sales channel to understand purchasing patterns.

### 6. Quarterly Sales Trend
Tracks quarterly sales performance to understand changes in sales across the year.

## 🔑 Key Insights

- Total sales reached approximately **₹2.33 Billion**.
- A total of approximately **1,774 vehicles** were sold.
- Dealer Sales Achievement reached **94.40%**.
- Dealer Unit Achievement reached **98.17%**.
- The dashboard identifies the **Top 5 Dealers** based on sales.
- State-wise analysis highlights the **Top 5 States** by sales.
- Sales performance is analyzed across different **car models, channels, customer types, and transmission types**.
